**The problem.** The official curriculum for the exam is spread across dozens of Trailhead modules and Help docs, with no single view and no weighting toward what the exam actually tests. Studying it front to back spends as much effort on a 5%-weighted domain as on a 35% one.

**The goal.** One study system weighted to the real exam blueprint (AI Agents 35%, Prompt Engineering 20%, Data 360 20%, Development Lifecycle 20%, Multi-Agent Interoperability 5%), built only on vetted sources, with every study artifact traceable back to a single source of truth.

**What I did.** Pulled the curriculum into one vetted source list, expanding module and trail hub pages down to the actual unit pages that hold the content. Reconciled conflicting domain weightings against Salesforce's published blueprint and corrected a mislabeled domain. Then built a generation chain off one set of consolidated notes: source material is summarized into those notes, and every study aid is generated from them, so a single correction propagates everywhere instead of being fixed in three places.

**The output.** A layered note set (quick-review and deep per-domain), a domain-weighted flashcard deck generated from a single file, a practice exam that draws a fresh weighted question set each attempt, and an effort-ordered study plan that front-loads the heavy domains. Copyrighted material is summarized, never reproduced; the study artifacts themselves stay private.

**Wider application.** None yet -- this one was built for my own cert prep. The method, though (vet the sources, weight to the real target, build on a single source of truth, generate the rest), is how I would build any onboarding or enablement curriculum where the inputs are messy and drilling people on wrong information is costly.
