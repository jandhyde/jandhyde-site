## What it's about

Knaflic's argument is that data presentations fail not because the data is bad but because the visual choices obscure the point. The book teaches a small set of design rules -- removing clutter, choosing the right chart for the right comparison, using color and emphasis sparingly -- aimed at making the takeaway impossible to miss.
